Powermove Native — panel states

The pictures for the build specs in panels/. Every card is one panel at its default size, drawn with pm-design tokens. They show the states a lane must build and a reviewer will compare against: empty, selected, hover, focus, editing, mixed, error, drop target, working. Where a spec and a picture disagree, the spec wins. Over-the-image chrome (badges, overlay capsule, gizmos) uses dark tokens in light mode too — language §4.
