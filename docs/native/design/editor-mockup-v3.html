Powermove Native — editor mockup v3

Refines the owner-approved v2 to language.md: system toolbar with a glass tool capsule, untinted sidebar toggles and one orange Export; solid neutral panels; a viewer bar with pop-ups instead of chips over the image; inspector rows on one shared value column with tabular numbers and muted units; timeline with neutral timecode, label-colour clips, a ring (not an orange fill) for selection and a render bar; a colour popover, the agent panel and a Composition Settings sheet. Every colour is a pm-design token.

Materials. Glass only on the toolbar, popover frame and sheet frame. Everything with dense content is solid; popover and sheet content sit on solid floating/panel material.
Accent as a mark. Orange appears on Export, the active tool glyph, the playhead, set keyframes, the selected thumbnail ring and the default button — nowhere as a large fill.
Numbers. SF Pro tabular figures, values left-aligned in 22 pt wells, units in muted after a space, one 128 pt value column.
