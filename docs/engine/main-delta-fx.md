### Implementation

`pm-fx-defs::catalog` retains all **43 current / 10 historical** full main
registrations and the **53 assembled GLSL programs**, generated by executing
main's own `toLegacyFx` against its own preamble. Source commit and blob ids are
recorded. The pre-existing v1.2.0 catalog is retained unchanged. Runtime consumes
Rust/JSON; the Node generator is a development oracle only.

Catalog lookup separates current API lookup from saved-instance lookup. Absent
or null saved versions mean 1; invalid or unavailable versions are errors.
History belongs to the winning provider, never an unrelated built-in with the
same id. Contextual defaults use source dimensions without clamping authored
values to presentation bounds.

**Historical conflict:** main's `gradient` legacy version 1 has layer-coordinate
uniforms, while tagged v1.2.0's unversioned Gradient uses composition coordinates.
Their defaults match, their shader sources do not. Both definitions remain
available through explicit `ReferenceGeneration`; `saved_definition` refuses an
ambiguous generation instead of guessing. The app/kernel still needs trustworthy
project provenance or an owner-approved migration policy. Do not invent provenance
from absent `Effect.version`, currently active workspace, or current registration.

`pm-fx-defs::inputs` validates four static layer/path/asset references, stage and
space, required null sentinels, paired path identity and UTF-16 id limits. Layer
remapping leaves path/asset ids untouched. Exact request identity includes time,
space, stage and exclusive owner prefix. Temporal/shutter times retain subframes
and negative shutter order. Input allocation uses checked arithmetic with the
reference's six-surface reserve.

`graph::input_plan` is an iterative producer-before-consumer scheduler with
shared-input deduplication, named cycles, 256 input leases and 65,536 nodes. Its
expansion callback must be supplied by the real evaluator: this does **not**
implement group/matte/backdrop/visibility policy or evaluate animated controls.
`spatial` ports mip level/byte and cell atlas calculations, layer kernel scale,
and off-composition source extent padding/union.

`pm-color::effect_transforms` ports signed D65 profile conversion, explicit
clipping/amount, premultiplied HDR companding and main's legacy SDR-preview
HDR/log treatment selection. These helpers do not change native original-media
interpretation or force SDR proxies. Color transform reference values come from
main's actual color-math functions. Compander tests check signed-HDR inversion
and alpha; they are not a GPU pixel oracle.

### Decisions and selecting rules

| Decision | Rule |
| --- | --- |
| Preserve both catalogs and diagnose the historical Gradient collision | N3 exact authored intent; N4 every old input remains available. Main's reused version number is not proof of original intent. |
| Store complete historical definitions, not patches against current defaults | N3/N4: later parameter/shader changes cannot reinterpret saved versions. |
| Missing versions/providers, cycles and resource failures remain errors | N1/N3; no blank pixels, substituted latest revision, or success-shaped fallback. |
| Keep exact timestamps, owner prefixes, stages and spaces in request keys | N3 authored timing and coordinates; N7 inspectable requests. |
| Do not advertise renderer capabilities from data or planning tests | N3/N6: current effects-basic requires eleven real capabilities, not labels. |
| Keep JS reference generation outside runtime and preserve original media tags | N8 no Node/Chromium in app; N3 original color intent; N4 no destructive preview conversion. |
| Keep all old consumers and v1.2.0 data | N4 and prune rule: no renderer/provider cutover has been proved. |

### Reproduction

All Rust commands run from `engine/` with the pinned Rust 1.96.1 toolchain.
Tests require no files outside owned `engine/` paths. The portable oracle is
committed and is read directly by Rust tests; Node is needed only to regenerate:

```sh
node --experimental-vm-modules engine/crates/pm-fx-defs/tools/generate-main.mjs --check
cd engine
cargo +1.96.1 test --locked -p pm-fx-defs
cargo +1.96.1 test --locked -p pm-color
cargo +1.96.1 test --locked -p pm-glsl --test main_effects
cargo +1.96.1 clippy --locked -p pm-fx-defs -p pm-color -p pm-glsl --all-targets -- -D warnings
cargo +1.96.1 fmt -p pm-fx-defs -p pm-color -p pm-glsl --check
```

The assembled-program gate tests validation/translation only. It neither draws
pixels nor certifies Metal pipelines. Do not relabel a portable contract or
shader compilation pass as completion of these rows.
