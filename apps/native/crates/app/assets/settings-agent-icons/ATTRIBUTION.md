# Other Agent Apps icons

- `openai-blossom.svg` is `OpenAI-logos/SVGs/OAI_OpenAI-Blossom_Black.svg` from the [official OpenAI logo archive](https://cdn.openai.com/brand/openai-logos.zip). The file is unchanged and the mark belongs to OpenAI. Its use here identifies Codex in the Settings list and follows the [OpenAI design guidelines and Marks usage terms](https://openai.com/brand/#usage-terms).
- `opencode.svg` is the unchanged [light square logo from Anomaly’s OpenCode repository](https://raw.githubusercontent.com/anomalyco/opencode/46f56ea2d0f73f02bfe144d3cf4faf7514ab9439/services/site/public/brand/files/opencode-logo-light-square.svg). See the [upstream MIT licence](https://github.com/anomalyco/opencode/blob/46f56ea2d0f73f02bfe144d3cf4faf7514ab9439/LICENSE) and local `LICENSE-OpenCode`. OpenCode and its logo are Anomaly trademarks and their use here identifies the OpenCode integration. See the [OpenCode brand guidelines](https://opencode.ai/brand#trademarks).
- Claude Code and Claude share the installed Claude app icon when available. The fallback is Apple’s `terminal` SF Symbol because Anthropic requires advance permission for bundled artwork. [Anthropic trademark guidelines](https://www.anthropic.com/legal/trademark-guidelines) [Claude Code legal and compliance](https://code.claude.com/docs/en/legal-and-compliance)
- Gemini CLI shows the installed Gemini app icon when available. The fallback is Apple’s `terminal` SF Symbol because Google requires approval to use its product icons. [Google product icon guidelines](https://partnermarketinghub.withgoogle.com/brands/google/branding-guidelines/how-to-show-googles-brand/#product-icons)
- Installed app icons come from macOS through `NSWorkspace`. Any Other Agent uses Apple’s `puzzlepiece.extension` SF Symbol.
