# Public synthetic packed-media inputs

`portable-media.pmv` is independently generated by `generate-portable.py` (Python
3.9+). Its PMV4 index and checksums cover a referenced one-pixel PNG and 1,024
unreachable opaque bytes. The acceptance probe compares **every embedded byte**,
media identity/type/revision, authored document and persisted Undo/Redo through
real MCP file ingress/save. These bytes establish packing, not decoding or pixels.
No FFmpeg, font, external project, account or platform asset is required.

`utf16-media.pmv` is the unmodified public synthetic
`engine/crates/pm-model/tests/fixtures/containers/pmv4.pmv` from integration base
`5bcd425ddc158cbd891ee4b515cf9993fad29a66`. It includes a deliberately lone
UTF-16 code unit. Vendoring keeps this lane's probe self-contained. The kernel
reader accepts it; the current MCP host's model-to-serde conversion panics.
The acceptance report preserves that **failure**, alongside the separate
save-in-place versus unique-export contract failure. Neither fixture contains
private/user media. Existing kernel corpus cases and original witnesses remain.

`scene3d-source-{catalog,read}.json` are unchanged public source-oracle fixtures
vendored from `apps/native/crates/mcp/fixtures` at the same integration base.
They retain their original source/hash metadata and independent expected values.
The source-backed 3D acceptance tests now use these owned snapshots, so they do
not require another lane's fixture directory to be present. No oracle value or
numeric comparison tolerance was changed.
